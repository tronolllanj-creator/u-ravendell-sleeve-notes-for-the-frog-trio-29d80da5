## What it is

`main.py` writes an album title and back-cover blurb (under 400 characters) for an amphibious jazz trio of frogs to `/output/entry.txt`. A discerning record shop owner judges these sleeve notes to find the ultimate amphibian cool.

## Run it

The program needs nothing but Python 3 and writes `/output/entry.txt`.

```sh
python3 main.py
```
